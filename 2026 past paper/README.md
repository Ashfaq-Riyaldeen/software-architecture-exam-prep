- `diagrams/q1_container.drawio` - C4 container diagram source.

- `diagrams/q1_context.svg` - rendered context diagram image.
- `diagrams/q1_container.svg` - rendered container diagram image.
- `diagrams/q1_deployment.svg` - rendered deployment diagram image.

Open the `.drawio` files with diagrams.net/draw.io to view, edit, or export them as images.
